Rocephin (Ceftriaxone) IM Calculator
A web-based tool designed to assist pediatric providers with calculating intramuscular (IM) Ceftriaxone doses, reconstitution volumes, and injection site safety limits.


📋 Features
Instant Volume Calculation: Determines the exact volume to draw based on the ordered dose and vial size.

Reconstitution Guide: Provides quick reference for how much 1% Lidocaine to add to 500mg or 1g vials.

Pediatric Safety Logic: automatically flags if a dose exceeds the safe volume for a single injection site based on patient age (Infant, Toddler, or Older Child).

Split-Dose Helper: If the volume is too large for one site, it calculates how many injections are required and the volume per injection.

⚙️ How it Works
The calculator uses standard reconstitution ratios for Ceftriaxone prepared with 1% Lidocaine:

1000 mg Vial: Adds 2.1 mL diluent → Total Yield: 2.9 mL (350 mg/mL)

500 mg Vial: Adds 1.0 mL diluent → Total Yield: 1.4 mL (350 mg/mL)

Injection Site Safety Limits
Infant (< 1 yr): Max 1.0 mL per site

Toddler (1–2 yrs): Max 1.5 mL per site

Child (> 2 yrs): Max 2.0 mL per site
